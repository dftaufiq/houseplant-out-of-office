A deterministic program that writes one 103-character out-of-office auto-reply, in the voice of a neglected houseplant, to /output/entry.txt for make.fun's "The Houseplant Out-of-Office" bounty.

## The entry

> Out of office. Dave watered me twice since March, both times coffee. If I die, bury me in the good pot.

## Run it

```sh
python3 main.py
```
